MONITORING STACK DEPLOYMENT GUIDE
=================================

OVERVIEW
--------
This configuration exposes Prometheus and Grafana dashboards via NodePort services, making them accessible from external browsers using the master node's floating IP address.

KEY CHANGES MADE
----------------

1. HEAT TEMPLATE (heat-template.yaml)
   - Added monitoring_security_group to master node (internal_port_1)
   - Updated monitoring_security_group rules to allow:
     * TCP 30000-32767 (NodePort range) from 0.0.0.0/0
     * TCP 9090 (Prometheus) from 0.0.0.0/0
     * TCP 3000 (Grafana) from 0.0.0.0/0
     * TCP 9093 (Alertmanager) from 0.0.0.0/0

2. PROMETHEUS PLAYBOOK (install-prometheus.yaml)
   - Changed Service type to NodePort
   - Assigned fixed nodePort: 30090
   - Removed duplicate EOF in deployment manifest

3. ALERTMANAGER PLAYBOOK (install-alertmanager.yaml)
   - Changed Service type to NodePort
   - Assigned fixed nodePort: 30093

4. GRAFANA PLAYBOOK (install-grafana.yaml)
   - Changed Service type to NodePort
   - Assigned fixed nodePort: 30030
   - Removed kubectl port-forward command
   - Added comprehensive access information display

DEPLOYMENT STEPS
----------------

1. Deploy OpenStack Heat Stack:
   openstack stack create -t heat-template.yaml kubernetes-cluster

2. Wait for stack creation and note the master node floating IP:
   openstack stack show kubernetes-cluster

3. Run Ansible playbooks in order:
   ansible-playbook -i inventory install-prometheus.yaml
   ansible-playbook -i inventory install-alertmanager.yaml
   ansible-playbook -i inventory install-grafana.yaml

ACCESSING DASHBOARDS
--------------------

After deployment, access the dashboards using your master node's floating IP:

GRAFANA:
URL: http://MASTER_FLOATING_IP:30030
Credentials: admin / admin

PROMETHEUS:
URL: http://MASTER_FLOATING_IP:30090

ALERTMANAGER:
URL: http://MASTER_FLOATING_IP:30093

Example:
If your master floating IP is 192.168.100.50:
- Grafana: http://192.168.100.50:30030
- Prometheus: http://192.168.100.50:30090
- Alertmanager: http://192.168.100.50:30093

SECURITY CONSIDERATIONS
-----------------------

The current configuration allows access from 0.0.0.0/0 (anywhere) for:
- NodePort range (30000-32767)
- Prometheus (9090)
- Grafana (3000)
- Alertmanager (9093)

For production environments, consider:
1. Restricting access by IP range using trusted_cidr parameter
2. Implementing authentication/authorization
3. Using Ingress with TLS instead of NodePort
4. Setting up VPN access for management interfaces

TROUBLESHOOTING
---------------

1. Check service status:
   kubectl get svc -n prometheus

2. Verify NodePorts:
   kubectl get svc grafana -n prometheus -o jsonpath='{.spec.ports[0].nodePort}'
   kubectl get svc prometheus -n prometheus -o jsonpath='{.spec.ports[0].nodePort}'
   kubectl get svc alertmanager -n prometheus -o jsonpath='{.spec.ports[0].nodePort}'

3. Check security groups:
   openstack security group list
   openstack security group rule list <security-group-id>

4. Verify pods are running:
   kubectl get pods -n prometheus

5. Check logs:
   kubectl logs -n prometheus <pod-name>
